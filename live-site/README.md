# نسخه نهایی سایت اُتسان (بک‌آپ)

این پوشه خروجی آماده‌ی (static build) سایت جدید اُتسان است که روی otsanelectronic.ir بالاست.
فایل‌ها همان‌طور که هستند روی هر هاست استاتیک (دارکوب، ابرآروان، Nginx) قابل انتشارند؛ فایل اصلی `index.html` است.

- صفحه‌ها: خانه، درباره ما، مقاله «سنسور حرکتی PIR»، و ۱۵ صفحه محصول زیر `products/`
- عکس‌ها، لوگو و فونت وزیرمتن: زیر `assets/`
- کاتالوگ PDF: `downloads/otsan-catalog.pdf`
- فایل‌های جاوااسکریپت و CSS ساخته‌شده Next.js زیر `next/` هستند

نکته: این خروجی ساخته‌شده (build) است، نه سورس قابل ویرایش Next.js. برای تغییرات کوچک می‌شود مستقیم HTML را ویرایش کرد.

بک‌آپ گرفته‌شده: ۱۸ آبان ۱۴۰۵
